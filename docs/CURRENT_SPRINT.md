## 🧠 1. Аналитика и Зафиксированные микро-решения спринта (Штаб)

* **Бизнес-цель**: Устранение узких мест эргономики:
  1. В конструкторе автоматизаций: при скоупе правила на доску триггер расписания не должен требовать выбор конкретной колонки; селекторы целевой доски и колонки должны быть четко сгруппированы по проектам и доскам вместо плоского списка.
  2. В управлении тегами: перевод тесного поповера в полноэкранный рабочий стол тегов (`TagManagerView`) в стиле «Автоматизаций» и «Архива».
  3. Задача профиля пользователя (TASK-B09) отложена по прямому указанию пользователя.

* **Связь с бэклогом**: [`docs/BACKLOG.md`](BACKLOG.md) (TASK-B14, TASK-B15, TASK-B09).

* **Принятые микро-решения**:

  1. **TASK-B14 (Автоматизации: расписание и группировка селекторов)**:
     - **Триггер расписания (`scheduled_sweep`)**:
       - В `RuleBuilderSections.tsx` / `useRuleBuilder.ts`: если выбран скоуп правила «На доску» (`board`), выбор колонки в триггере становится опциональным («Все колонки доски» по умолчанию). Если выбран скоуп «На колонку» (`column`), колонка привязана к контексту.
       - В `backend/internal/application/automation/worker.go`: при `rule.ColumnID == nil && rule.BoardID != nil` воркер запускает sweep по всем колонкам указанной доски.
     - **Иерархическая группировка в селекторах**:
       - В селекторе целевой доски: группировка `<optgroup label="Проект: {projectName}">` → доски проекта.
       - В селекторе целевой колонки: группировка `<optgroup label="{projectName} → {boardName}">` → колонки доски.
       - Обновление применяется в `RuleBuilderSections.tsx`, `MoveTaskModal.tsx` и `RestoreTaskPopover.tsx`.

  2. **TASK-B15 (Полноэкранный Менеджер тегов в MainSheet)**:
     - В `MainSheet.tsx` добавляется обработка `activeView === 'tags'` и URL `/tags`.
     - Создается `frontend/src/features/tag-manager/TagManagerView.tsx`:
       - Верхняя панель: заголовок «Теги», быстрый поиск тегов, кнопка «Удалить неиспользуемые» с бейджем количества.
       - Основная рабочая область: просторная сетка карточек тегов (название, цветной бейдж, счетчик задач, 12-цветная палитра для быстрой смены цвета в 1 клик, удаление).
       - Поддержка состояний: Skeleton при загрузке, Empty («Теги пока не созданы»), ErrorBanner.
     - В `Sidebar.tsx`: по клику на пункт «Теги» переключается вид `onNavigate('tags')` вместо открытия тесного поповера.
