## 🧠 1. Аналитика и Зафиксированные микро-решения спринта (Режим «Штаб»)

* **Бизнес-цель**: Обеспечить максимальный простор для Канбан-доски (Canvas-First) и устранить тесноту статичной 3-колоночной компоновки: полный коллапс сайдбара по хоткею `[`, перемещение MiniCalendar в сайдбар, и замена статичного правого инспектора на плавный выдвижной Task Drawer (560px) с быстрыми действиями и режимом non-modal на десктопе.
* **Зафиксированные архитектурные и продуктовые микро-решения**:
  1. **Сворачиваемый сайдбар (Collapsible Sidebar — Вариант Б)**:
     - Полное скрытие сайдбара за левый край (`-100%` / `w-0` с плавной CSS-кинетикой `duration-300`).
     - Глобальный хоткей переключения: `[` (а также клик по кнопке в шапке / сайдбаре).
     - При свернутом сайдбаре появляется изящная кнопка раскрытия в левом верхнем углу холста.
     - Состояние (`isSidebarOpen`) сохраняется в `localStorage`.
  2. **Перенос MiniCalendar в сайдбар**:
     - Компактная матричная сетка `MiniCalendar` интегрируется в нижнюю часть левого сайдбара (аккордеон/секция под списком проектов).
     - Полностью освобождается правая зона приложения под Канбан-доску и шторку Drawer.
  3. **Выдвижной Task Drawer (560px — Вариант А: Non-modal Sheet)**:
     - Шторка выезжает справа (`fixed top-0 right-0 h-full w-full max-w-[560px] z-40 bg-surface border-l border-subtle shadow-washi-lg`).
     - Плавная кинетика открытия/закрытия: `translate-x-0` $\leftrightarrow$ `translate-x-full` с кривой `cubic-bezier(0.22, 1, 0.36, 1)`.
     - **Non-modal на десктопе (`lg:`)**: фон не затемняется, пользователь может продолжать видеть доску и кликать по другим карточкам, мгновенно переключая контекст шторки.
     - **Modal на мобильных/планшетах (`< lg`)**: полупрозрачный backdrop оверлей с закрытием по тапу вне шторки.
     - Закрытие по клавише `Esc` и кнопке крестика в шапке шторки.
  4. **Панель быстрых действий (Action Bar) в шапке Task Drawer**:
     - Кнопки-капсулы быстрых действий:
       * `+ Срок`: контекстный выбор дедлайна.
       * `+ Вложение`: вызов диалога загрузки файла в S3.
       * `+ Тег`: выпадающий список добавления тегов воркспейса.
       * `⭐ Сегодня`: тумблер добавления в фокус дня (`focusOrder`).
       * `Статус`: селектор быстрой смены колонки проекта.
     - Полноразмерный Markdown-редактор с поддержкой `Ctrl+V` вставки скриншотов и галерея прикрепленных файлов.
