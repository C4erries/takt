## 🧠 1. Аналитика и Зафиксированные микро-решения спринта (Режим «Штаб»)

* **Бизнес-цель**: Реализовать контекстные автоматизации на уровне конкретных колонок Канбан-доски с готовыми пресетами («из коробки»), а также возможность выделить одну колонку проекта под Inbox для мгновенного сброса задач через Quick Capture (хоткей `C`).

* **Принятые продуктовые и технические решения (Согласовано с пользователем)**:
  - **D-061-1 (Выделенная Inbox-колонка в проекте)**:
    - Поле `is_inbox: boolean` в таблице `columns` (на доске может быть ровно 0 или 1 Inbox-колонка).
    - В выпадающее меню действий колонки (`...`) добавляется пункт «Сделать входящей (Inbox)» / «Снять статус Inbox». При назначении у других колонок этой доски флаг `is_inbox` автоматически снимается.
    - В заголовке колонки отображается аккуратная иконка `Inbox` рядом с названием, показывающая, что колонка принимает входящие.
    - При быстром захвате (`Quick Capture` / хоткей `C`), если открыт проект и на текущей доске есть назначенная Inbox-колонка, задача создается сразу в ней с соответствующим `project_id` и `column_id`. Если проект не открыт или Inbox-колонки нет — задача создается в общем Inbox воркспейса.
  - **D-061-2 (Минималистичный UI автоматизаций колонки)**:
    - Пункт «Автоматизации колонки (⚡)» размещается **строго внутри выпадающего меню `...`** колонки, чтобы не загромождать шапку лишними кнопками.
    - При выборе открывается модальное окно управления правилами конкретно для этой колонки с готовыми пресетами и тумблерами.
  - **D-061-3 (Архитектура данных и движка событий в БД/API)**:
    - Миграция БД:
      - Таблица `columns`: добавление `is_inbox BOOLEAN NOT NULL DEFAULT FALSE`.
      - Таблица `automations`: добавление `column_id UUID NULL REFERENCES columns(id) ON DELETE CASCADE`.
    - Типы триггеров и пресеты для колонок:
      * `TASK_ENTERED_COLUMN`: при перемещении или создании задачи в этой колонке $\rightarrow$ автоматическое изменение приоритета (например, в колонку «Срочно» $\rightarrow$ `High`/`Urgent`) или добавление тега.
      * `TASK_COMPLETED_IN_COLUMN`: при клике по чекбоксу задачи в этой колонке $\rightarrow$ автоматическое перемещение в выбранную целевую колонку (например, задача из «Ревью» перемещается в «Готово»).
    - Защита от циклов (`Cycle Guard`): счетчик цепочки вызовов в `context.Context` (не более 3 последовательных автоматизаций на одно первичное действие пользователя).
