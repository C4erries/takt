## 🧠 1. Аналитика и Зафиксированные микро-решения спринта (Режим «Штаб»)

* **Бизнес-цель**: Сделать Low-Code конструктор правил интуитивным и дружелюбным: избавить пользователя от ввода сырого текста в условиях, предоставить специализированные селекторы значений под каждое поле («Да»/«Нет» для булевых полей, быстрые пресеты и календарь для дедлайнов, цветные чипы для приоритетов), реализовать оператор «Один из» (`in`) для задания наборов допустимых значений (OR-логика) + наглядный выбор связки И/ИЛИ между строками, добавить действия авто-выполнения задач («Отметить выполненной» / «Снять выполнение») и условие «Статус дедлайна».

* **Зафиксированные микро-решения спринта (Решения Штаба)**:
  - **D-065-1 (Контекстные селекторы значений под каждое поле условия)**:
    - *Для поля «Завершена» (`is_completed`)*:
      - Никаких текстовых полей ввода! Отображаются две четкие кнопки-пилюли: **`[ Да (выполнена) ]`** и **`[ Нет (в работе) ]`** (`value: true` / `false`).
      - Доступные операторы: `равно` (`equals`) / `не равно` (`not_equals`).
    - *Для поля «Приоритет» (`priority`)*:
      - При `equals` / `not_equals`: выпадающий список с цветными Washi-маркерами (`Срочный` 🔵, `Высокий` 🟠, `Средний` 🌾, `Низкий` 🌿, `Обычный`).
      - При операторе `in` («Один из»): кликабельные чипы-мультиселекторы (например, выбор одновременно `[✓ Срочный] [✓ Высокий]`).
    - *Для поля «Дедлайн» (`due_date`)*:
      - Операторы: `равно`, `раньше чем (до)`, `позже чем (после)`, `заполнено`, `пусто`.
      - Быстрые пресеты в 1 клик: `[ Сегодня ]`, `[ Завтра ]`, `[ Просрочен ]` + нативный календарный выбор точной даты (`YYYY-MM-DD`).
    - *Для поля «Теги» (`tags`)*:
      - Операторы: `содержит`, `не содержит`, `один из` (`in`), `заполнено`, `пусто`.
      - Селектор существующих тегов воркспейса + ввод кастомного тега.
    - *Для поля «Время в колонке» (`time_in_column_hours`)*:
      - Операторы: `больше чем`, `меньше чем`.
      - Быстрые кнопки пресетов: `[ 24 ч ]`, `[ 48 ч ]`, `[ 72 ч ]` + числовой ввод с суффиксом «ч».
  - **D-065-2 (Логика «ИЛИ» и набор допустимых значений — оба варианта)**:
    - *Вариант 1 (Оператор «Один из» / `in`)*: Добавлен оператор `in` («один из») и `not_in` («ни один из») в `Condition` (OpenAPI `automation.yaml`, домен `rule.go` и `evaluator.go`). В UI конструктора выбор значений через множественные чипы (для приоритета и тегов).
    - *Вариант 2 (Наглядная связка между строками)*: Прямо между строками условий отображается интерактивный бейдж связки: `[ ЕСЛИ ] Условие 1` $\rightarrow$ `[ И ▾ / ИЛИ ▾ ]` $\rightarrow$ `Условие 2`. Пользователь визуально видит и может переключать логическую связку.
  - **D-065-3 (Новые действия Low-Code)**:
    - ✅ **«Отметить выполненной»** (`mark_completed`): выставляет `is_completed = true`.
    - 🔄 **«Снять отметку выполнения»** (`mark_uncompleted`): снимает отметку `is_completed = false`.
    - 🗑️ **«Очистить дедлайн»** (`clear_due_date`): сбрасывает срок задачи (`due_date = nil`).
    - *(Действия «фокус Сегодня» исключены по согласованию с пользователем)*.
  - **D-065-4 (Новое условие Low-Code)**:
    - ⚠️ **«Статус дедлайна»** (`due_date_status`): значения `overdue` (Просрочен), `due_soon` (Горит <= 48ч), `no_due_date` (Без срока), `on_track` (В графике).
    - *(Условие «в фокусе Сегодня» исключено по согласованию с пользователем)*.
