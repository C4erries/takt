## 🧠 1. Аналитика и Зафиксированные микро-решения спринта (Режим «Штаб»)

* **Бизнес-цель**: Устранить потерю контекста при обновлении страницы (`F5`) или переходе по прямым ссылкам. Сейчас при перезагрузке вкладки приложение всегда сбрасывается в Inbox, требуя повторных кликов по проекту и доске. Необходимо реализовать полноценный URL-роутинг и deep linking, чтобы адресная строка браузера отражала активный проект, доску и открытую задачу.

* **Продуктовые и технические микро-решения спринта**:
  - **D-055-1 (Формат и семантика URL-маршрутов)**:
    - `/` или `/inbox` $\rightarrow$ Входящие задачи (`activeNav: 'inbox'`).
    - `/today` $\rightarrow$ Задачи на сегодня (`activeNav: 'today'`).
    - `/projects/:projectId` $\rightarrow$ Проект (при загрузке автоматически выбирается первая доска).
    - `/projects/:projectId/boards/:boardId` $\rightarrow$ Проект + конкретная доска (`selectedProjectId = projectId`, `activeBoardId = boardId`).
    - Query-параметр `?task=:taskId` $\rightarrow$ Открытие Task Drawer (выдвижной инспектор деталей задачи) поверх любого экрана.
  - **D-055-2 (Двусторонняя реактивная синхронизация через History API)**:
    - Реализация хука `useUrlSync.ts` в `src/features/task-navigation/` (чистый, легковесный, без тяжелых внешних зависимостей).
    - При клике пользователя на сайдбар, проект, карточку доски или задачу: URL плавно обновляется через `history.pushState` (для смены экрана/доски) или `history.replaceState` (для параметров/открытия шторки).
    - Слушатель `window.addEventListener('popstate')`: при нажатии браузерных кнопок «Назад» / «Вперед» мгновенно синхронизирует состояние `taskStore`.
  - **D-055-3 (F5-safety & Deep Link Resolution)**:
    - При первоначальной загрузке приложения парсить текущий `window.location.pathname` и `window.location.search`.
    - Инициализировать `taskStore` правильными `activeNav`, `selectedProjectId`, `activeBoardId`, `selectedTaskId`.
    - Если перешли по маршруту `/projects/:projectId` без указания доски, после получения списка досок (`useProjectBoardsQuery`) автоматически выбирать первую доску и дополнять URL до `/projects/:projectId/boards/:boardId` через `replaceState`.
    - Сохранение последнего активного URL в `localStorage` (`takt_last_route`), чтобы при заходе на чистый домен `/` пользователь возвращался туда, где остановился.
  - **D-055-4 (Обработка крайних случаев и 404)**:
    - Если передан `boardId`, которого нет среди досок проекта (удален или опечатка), выполнить fallback на первую доступную доску проекта.
    - Если передан `projectId`, которого нет в воркспейсе (404/403), выполнить мягкий редирект в `/inbox`.
