# Дорожная карта проекта Takt (`ROADMAP.md`)

> Общий стратегический план развития проекта Takt.
> Каждая фаза представляет собой self-contained майлстоун с работающим продуктовым результатом и 100% прохождением архитектурного и тестового контроля.
>
> **Легенда статусов**: 🔲 Planned (Запланировано) · 🔵 In Progress (В работе) · ✅ Done (Завершено) · ⏸️ Paused (На паузе)

---

## Фаза 0: Инженерный фундамент, Архитектурный линтер и UI-Kit «Soft Editorial GTD» ✅
> **Цель**: Развернуть каркас монорепозитория в Docker Compose, настроить автоматический архитектурный контроль `make check-arch`, мультифайловый OpenAPI и создать атомарный UI-Kit по Дизайн-паспорту японской канцелярии.

- [x] Инициализация структуры монорепозитория (`backend/`, `frontend/`, `deploy/`, `tests/`, `scripts/`, `docs/`, `api/`).
- [x] Базовый Go-сервис на **Echo v4** с точкой сборки зависимостей `backend/internal/infrastructure/container/` (`main.go` < 50 строк).
- [x] Настройка пула БД `pgxpool`, транзактора через `context.Context` и конфигурации `sqlc.yaml`.
- [x] Настройка скрипта **`scripts/check_arch.sh` и команды `make check-arch`** (лимит строк < 400, лимит файлов в доменном пакете <= 7, запрет сырых цветов Tailwind, чистота слоев DDD).
- [x] Мультифайловый OpenAPI манифест (`api/openapi/*`), сборка через `@redocly/cli` и генерация через `oapi-codegen`.
- [x] Базовая инфраструктура: `docker-compose.yml` (PostgreSQL 16, Backend, Frontend, Nginx reverse-proxy) и `Makefile`.
- [x] Базовый атомарный **UI-Kit в `frontend/src/shared/components/ui/`** (`Button`, `Input`, `Checkbox` 18px круглый, `Card`, `Badge` капсульный, `Modal`, `Skeleton`, `EmptyState`, `ErrorBanner`) на токенах Washi/Matcha.
- [x] Каркас E2E-тестирования на Python (`pytest` + `httpx`) в `tests/` с фикстурами API-клиента.

## Фаза 1 (Этап 0.2): Авторизация, Персональный Workspace и Захват в Inbox (Quick Capture) ✅
> **Цель**: Полный цикл Zero-friction онбординга (регистрация $\rightarrow$ вход в личный воркспейс), быстрый сбор входящих мыслей/задач в Inbox с J/K навигацией.

- [x] Доменный пакет `internal/domain/workspace` и таблица `workspaces` (автосоздание `personal` воркспейса).
- [x] Авторизация (JWT в HTTP-only cookies / Header), хеширование паролей, Echo middleware аутентификации и Tenant Isolation.
- [x] Доменный пакет `internal/domain/task` и хранилище задач Inbox (`project_id` и `column_id` nullable).
- [x] Быстрый захват задач (Quick Task Capture): хоткей добавления, сохранение заголовка и заметок.
- [x] Фронтенд-каркас «Surface-on-Canvas» (3 колонки): левый сайдбар навигации + центральный лист Washi с разлиновкой задач.
- [x] Пружинная J/K клавиатурная навигация по строкам задач и переключение круглого чекбокса выполнения.
- [x] Сквозные Pytest E2E-тесты: регистрация, создание задач в Inbox, отметка выполнения, защита от неавторизованного доступа.

## Фаза 2: Проекты, Канбан-доски, Фокус «Сегодня» и Пресеты Автоматизаций ✅
> **Цель**: Организация задач по проектам и колонкам статусов, фокусный вид «Focus of the Day», правая Bento-панель (инспектор задачи + матричный календарь) и запуск фонового движка автоматизаций v1.

- [x] Доменные пакеты `internal/domain/project` (проекты, доски, упорядоченные колонки со статусами).
- [x] Канбан-доска с drag-and-drop карточек на `@dnd-kit/core` + переключение в плоский вид Списка (List View).
- [x] Фокус-вид «Сегодня / Focus of the Day» с отбором задач по дедлайну или приоритету фокуса.
- [x] Правая панель Bento: инспектор задачи (Markdown-описание, капсульные теги контекста) + матричный календарь с 1px границами.
- [x] Движок событий `internal/domain/events` (`EventBus`) и доменный пакет `internal/domain/automation`.
- [x] Реализация 3 пресетных правил с тумблерами Вкл/Выкл в интерфейсе:
  1. *Inbox Zero*: Задаче назначен проект/срок $\rightarrow$ автоперемещение из Inbox.
  2. *Done & Archive*: Чекбокс отмечен $\rightarrow$ автоперенос в колонку «Done» и дата завершения.
  3. *Auto-Focus*: Срок задачи наступил «Сегодня» $\rightarrow$ автоперевод в активный статус / фокус.
- [x] E2E-тесты на Pytest: полный цикл перемещения карточек, срабатывание автоматизаций при смене чекбокса/даты (25/25 PASS).

## Фаза 4: Пространственный UI/UX, Выдвижной инспектор (Drawer), Эргономика Досок и Мультипалитры 🔲
> **Цель**: Максимальное рабочее пространство под Канбан-доски, быстрое переключение контекстов, выдвижное окно редактирования задачи (Slide-out Drawer) с полными метаданными и гибкий движок цветовых тем/палитр.

- [ ] **Максимальный простор для Канбан-доски (Canvas-First Layout)**:
  - Сворачиваемый/компактный левый сайдбар (Collapsible Sidebar), освобождающий всю ширину экрана под доску.
  - Крупный и удобный переключатель воркспейсов в шапке сайдбара с быстрыми аватарами.
  - Выразительный переключатель досок проекта (Board Switcher): быстрые вкладки-пилюли сверху или компактный саб-бар со счетчиками задач.
  - Свободные, просторные колонки с удобным горизонтальным скроллом и информативными карточками задач.
- [ ] **Выдвижное окно редактирования задачи (Slide-out Task Drawer)**:
  - Плавный выезд справа на `520–600px` (Slide-over Sheet), не перекрывающий доску на широких экранах и сохраняющий контекст.
  - Панель быстрых действий: `+ Подзадача`, `+ Файл` (S3), `+ Связь` (зависимости), `+ Время` (старт, дедлайн, эстимейт), `+ Автоматизация` (привязать готовое правило).
  - Структурированные мета-поля: Исполнители, Проект и Колонка статуса, Дата начала и Срок, Оценка времени, Приоритет, Теги-капсулы.
  - Полноразмерный Markdown-редактор заметок с поддержкой заголовков, чекбоксов `[ ]` и превью картинок.
  - Секция комментариев и лента истории изменений по задаче внизу окна.
- [ ] **Движок мультипалитр и тем оформления (Theme Engine)**:
  - Базовая палитра: «Midori Washi & Matcha» (рисовая бумага, чай матча, сухой бамбук, чернила суми).
  - Темная тема: «Sumi Obsidian» (Dark Mode First: фактурный древесный уголь, бархатный глубокий фон, пепел, бамбуковый акцент).
  - Сезонные и тематические палитры:
    * «Kyoto Persimmon» (теплая осенняя хурма, терракота, крафт-бумага).
    * «Winter Washi / Xmas» (зимний белый лен, хвоя, клюквенный/рябиновый акцент).
  - Мгновенное переключение тем через семантические CSS-токены без перезагрузки страницы (Zustand + `localStorage`).
- [ ] **Эргономика, кинетика и хоткеи Linear-класса**:
  - Пружинные анимации открытия/закрытия Drawer и перемещения карточек (`cubic-bezier(0.22, 1, 0.36, 1)`).
  - Полная поддержка клавиатуры: закрытие шторки по `Esc`, навигация по доске стрелками и `J/K`, хоткеи фокуса.

## Фаза 5: Конструктор автоматизаций v2 (Low-Code Automation Engine) 🔲
> **Цель**: Развитие движка автоматизаций до полноценного визуального Low-Code конструктора пользовательских правил, сложных цепочек условий и фоновых таймеров.

- [ ] **Визуальный конструктор правил (Visual Rule Builder)**:
  - Интерфейс создания правил в стиле «Триггер $\rightarrow$ Условия $\rightarrow$ Действия» (Trigger-Condition-Action).
  - Поддержка составных условий (логика AND / OR, сравнение полей, проверка тегов, приоритета, исполнителя).
  - Богатый набор действий: перемещение по колонкам, назначение дедлайна/старта, добавление тегов, архивация, создание связанных подзадач.
- [ ] **Фоновые тайм-триггеры и периодический тикер (Time Engine)**:
  - Правила по расписанию и времени («если задача висит в колонке более N дней», «за 24 часа до дедлайна»).
  - Фоновый воркер периодических проверок и утренней группировки задач.
- [ ] **Песочница тестирования и журнал выполнения (Execution Log)**:
  - Тестовый прогон правила на выбранной задаче перед активацией.
  - Детальный лог срабатываний правил в воркспейсе для легкой отладки пользователем.
