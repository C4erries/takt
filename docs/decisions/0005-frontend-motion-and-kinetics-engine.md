# ADR-0005: Движок кинетики и анимаций интерфейса (Frontend Animation Engine)

* **Дата**: `2026-10-19`
* **Статус**: `Accepted`
* **Инициатор / Автор**: `Pavel (Founder) & Lead AI Architect`
* **Затрагиваемые подсистемы**: `frontend/src/shared/lib/motion`, `frontend/src/shared/components/ui`, `frontend/src/features/kanban-board`, `frontend/src/widgets/task-drawer`

---

## 🎯 1. Контекст и Проблема (Context)

В рамках Фазы 7 (Спринт 0.7.3 — Вывод к MVP 1.0) интерфейсу Takt требуется переход от статичных и разрозненных CSS-переходов к целостной кинетической системе (*Animation Engine*).
Продукт выполнен в эстетике *Japanese Stationery / Soft Editorial GTD* (бумага Washi, чернила Sumi, чай Matcha). Интеракции должны ощущаться физически осязаемыми:
* Завершение задачи не должно быть мгновенным сухим исчезновением; пользователю необходимо тактильное подтверждение выполненного действия («чернильное вычеркивание» и микро-пауза перед схлопыванием).
* Выдвижные панели (Drawer) и модальные окна должны обладать естественной инерцией и демпфированием бумажного свитка/листа.
* Добавление колонок и перестроение списков не должны вызывать дерганья макета и скачков скролла.
* Все анимации обязаны строго соблюдать стандарт доступности `prefers-reduced-motion` (WCAG 2.1), не перегружая бандл и не замедляя 60 FPS интерфейса.

## 📐 2. Принятое архитектурное решение (Decision)

### 1. Технологическая основа: `motion` (`motion/react` 12+)
В качестве библиотеки анимаций принимается **`motion`** (современное развитие `framer-motion` под React 18/19).
* **Обоснование**: 
  - Нативная поддержка `AnimatePresence` для фазы исчезновения (exit animations) удаляемых и перемещаемых карточек.
  - Декларативное управление физикой пружин (`spring physics`) на базе `stiffness`, `damping`, `mass`.
  - Встроенный механизм `layout`-анимаций, устраняющий дерганье соседних элементов при схлопывании карточек.
  - Отличный tree-shaking и совместимость с TypeScript и Tailwind CSS.

### 2. Централизация кинетических токенов (`shared/lib/motion/`)
Все параметры физики пружин, константы длительностей и фабрики анимационных вариантов выносятся в единый модуль `frontend/src/shared/lib/motion/` (с лимитом `<= 7` файлов):
* `springs.ts`:
  - `springTactile`: `{ type: 'spring', stiffness: 420, damping: 30, mass: 0.8 }` — мгновенный тактильный отклик (чекбоксы, микро-поп, кнопки).
  - `springSheet`: `{ type: 'spring', stiffness: 300, damping: 32, mass: 1 }` — инерция крупных поверхностей (Drawer, модальные окна).
  - `springLayout`: `{ type: 'spring', stiffness: 340, damping: 28 }` — плавное перестроение списков и сетки колонок.
* `reducedMotion.ts`:
  - Хук `useReducedMotionPreference()` для детекции системных настроек пользователя (`@media (prefers-reduced-motion: reduce)`).
  - Утилита `withReducedMotion(springVariant, fadeFallback)` — адаптивное затухание (Dampening): замена сдвигов координат (x/y) и масштабирования (scale) на деликатный фейд (`opacity: 100ms`).
* `variants.ts`:
  - Готовые пресеты для списков карточек, выезжающих шторок, вычеркивания текста и модалок.

### 3. Хореография микро-интеракций
* **Чекбокс завершения задачи**:
  1. *Фаза 1 (Отклик)*: клик вызывает микро-поп чекбокса (`scale: [1, 0.88, 1.08, 1]`) и прорисовку галочки.
  2. *Фаза 2 (Чернильное вычеркивание)*: анимированная чернильная линия (`strike-through`) плавно перечеркивает заголовок слева направо (160ms).
  3. *Фаза 3 (Фиксация триумфа)*: пауза 350ms, позволяющая зафиксировать завершение дела.
  4. *Фаза 4 (Схлопывание)*: плавное исчезновение карточки (`opacity: 0, height: 0, marginBottom: 0`) с автоматическим мягким подтягиванием соседних карточек.
* **Task Drawer & Modal**:
  - Пружинное выдвижение с правого края (`x: ['100%', '0%']`) с мягким демпфированием без пробивания экрана.
  - Backdrop с плавным появлением (`opacity: [0, 1]`, duration: 200ms).
* **Колонки Канбана**:
  - Анимированное раскрытие новой колонки при создании (`width: 0 -> 280px, opacity: 0 -> 1`) без рывков горизонтального скролла.
* **Тактильный микро-отклик кнопок**:
  - Легкое упругое нажатие (`whileTap: { scale: 0.97 }`) на кнопках, чипах фильтров и табах.

## ⚡ 3. Последствия и Риски (Consequences)

### Положительные:
1. Интерфейс приобретает фирменную тактильность японской канцелярии, выделяющую Takt на фоне сухих корпоративных таск-трекеров.
2. Исключены визуальные рывки при закрытии задач и добавлении колонок.
3. Полная доступность: пользователи с вестибулярной чувствительностью защищены автоматическим подавлением сдвигов.
4. Единый API для разработчиков: отсутствие хаотичных разрозненных классов `transition-*` в десятках компонентов.

### Риски и Компромиссы:
1. **Размер бандла**: Добавление пакета `motion` увеличивает размер клиентского бандла примерно на 25–30 КБ (gzipped). Это оправдано для ключевой ценности продукта MVP 1.0.
2. **Конфликты с DND**: При перетаскивании карточек `@dnd-kit` управляет `transform`. Интеграция `motion` требует корректного разделения состояний `isDragging` (когда dnd-kit перехватывает управление стилями).
