## 🧠 1. Зафиксированные микро-решения спринта (Preserved Micro-Decisions)

> *Сохраненные продуктовые и технические правила, принятые в Фазе А («Штаб») этого спринта:*

* **Бизнес-цель**: Обеспечить максимальный простор для Канбан-доски (Canvas-First) и устранить тесноту жесткой 3-колоночной компоновки: полный коллапс сайдбара по хоткею `[`, интеграция `MiniCalendar` в левый сайдбар, и замена статичного правого инспектора на плавный выдвижной Task Drawer (560px) с быстрыми действиями и режимом non-modal на десктопе.
* **Ключевые продуктовые правила и UX-решения**:
  1. **Сворачиваемый сайдбар (Collapsible Sidebar — Вариант Б)**:
     - Полное скрытие сайдбара за левый край (`-100%` / `w-0` с плавной CSS-кинетикой `duration-300`).
     - Глобальный хоткей переключения: `[` (а также клик по кнопке `PanelLeftClose` в шапке сайдбара).
     - При свернутом сайдбаре появляется кнопка раскрытия `PanelLeftOpen` в левом верхнем углу холста.
     - Состояние открытости (`isSidebarOpen`) сохраняется в `localStorage` (`takt_sidebar_open`).
  2. **Интеграция MiniCalendar в сайдбар**:
     - Компактная матричная сетка `MiniCalendar` интегрирована в нижнюю часть левого сайдбара (под списком проектов).
     - Полностью освобождена правая зона приложения под просторный холст Канбан-доски и выдвижной Drawer.
  3. **Выдвижной Task Drawer (560px — Non-modal Sheet)**:
     - Шторка выезжает справа (`fixed top-0 right-0 h-full w-full max-w-[560px] z-40 bg-surface border-l border-subtle shadow-washi-lg`).
     - Пружинная кинетика открытия/закрытия: `translate-x-0` $\leftrightarrow$ `translate-x-full` с кривой `cubic-bezier(0.22, 1, 0.36, 1)`.
     - **Non-modal на десктопе (`lg:`)**: фон не затемняется, пользователь продолжает видеть доску и может переключать задачи кликом по другим карточкам без лишних закрытий.
     - **Modal на мобильных/планшетах (`< lg`)**: полупрозрачный backdrop-оверлей с закрытием по тапу вне шторки.
     - Закрытие по клавише `Esc` и кнопке крестика в шапке шторки.
  4. **Панель быстрых действий (Quick Action Bar) в шапке Task Drawer**:
     - Кнопки-капсулы быстрых действий:
       * `+ Срок`: контекстный выбор дедлайна.
       * `+ Вложение`: вызов диалога загрузки файла в S3.
       * `+ Тег`: выпадающий список тегов воркспейса.
       * `⭐ Сегодня`: тумблер добавления в фокус дня (`focusOrder`).
       * `Статус`: селектор быстрой смены колонки проекта.
     - Полноразмерный Markdown-редактор с поддержкой `Ctrl+V` вставки скриншотов и галерея прикрепленных файлов.

## 🎯 2. Ключевые результаты и Затронутые подпакеты

1. **Пользовательский интерфейс (`frontend/src/`)**:
   - `frontend/src/widgets/sidebar/Sidebar.tsx`:
     * Реализовано сворачивание с CSS-переходом `transition-all duration-300 ease-in-out`.
     * Глобальный слушатель хоткея `[` (с фильтрацией событий ввода в `input`, `textarea`).
     * Встроен компактный `MiniCalendar` под секцией проектов.
   - `frontend/src/widgets/mini-calendar/MiniCalendar.tsx`:
     * Добавлен пропс `isCompact` для органичного встраивания в сайдбар (уменьшенные отступы, компактные 1px ячейки).

     * `TaskDrawer.tsx`: полнофункциональная шторка 560px, Non-modal на десктопе, закрытие по `Esc` и клику вне шторки на мобильных.
     * `QuickActionBar.tsx`: капсульные действия с поповерами выбора даты, тегов, колонок статуса и добавления файлов.
     * `index.ts`: чистый экспорт модуля виджета.
   - `frontend/src/app/App.tsx`:
     * Удалена статичная 3-я колонка Bento; `MainSheet` расширен до 100% ширины рабочего пространства (Canvas-First).
     * Размещен выдвижной `TaskDrawer`, управляемый стейтом `selectedTaskId`.
     * Добавлена плавающая кнопка разворачивания сайдбара при его закрытии.
2. **Инфраструктура тестов (`tests/conftest.py`)**:
   - Добавлена автоматическая инициализация S3-бакета `takt-attachments` при старте тестов для гарантированной стабильности после перезапусков контейнеров.
