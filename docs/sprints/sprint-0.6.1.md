## 🎯 Цели и Результаты спринта

1. **Выделенная Inbox-колонка в проекте (Designated Inbox Column)**:
   - Миграция БД `000008_column_automations_and_inbox.up.sql`: добавлен флаг `is_inbox BOOLEAN NOT NULL DEFAULT FALSE` в таблицу `columns` и частичный уникальный индекс `idx_columns_board_inbox` на `(board_id) WHERE is_inbox = true`.
   - В выпадающее меню действий колонки (`...`) добавлен пункт «Сделать входящей (Inbox)» / «Снять статус Inbox».
   - В шапке колонки отображается акцентный значок `Inbox`.
   - Маршрутизация `Quick Capture` (`C`): при создании задачи в рамках проекта с выделенной Inbox-колонкой задача создается прямо в ней с соответствующими `project_id` и `column_id`.

2. **Автоматизации на уровне конкретной колонки (Column-Level Automations & Presets)**:
   - В таблице `automations` добавлена колонка `column_id UUID NULL REFERENCES columns(id) ON DELETE CASCADE`.
   - Добавлены типы триггеров `TASK_ENTERED_COLUMN` и `TASK_COMPLETED_IN_COLUMN`.
   - Пункт «Автоматизации колонки (⚡)» встроен в меню действий колонки `...`.
   - Модальное окно [ColumnAutomationsModal.tsx](file:///home/pavel/projects/takt/frontend/src/features/kanban-board/ColumnAutomationsModal.tsx) с готовыми пресетами:
     * *Смена приоритета*: при добавлении задачи в колонку автоматически выставляется заданный приоритет (например, «Срочно»).
     * *Автоперенос при выполнении*: при отметке чекбокса задачи в колонке карточка автоматически переносится в выбранную целевую колонку (например, «Готово»).
   - Активное клиентское и бэкенд исполнение: правила мгновенно отрабатывают при DND-переносе, инлайн-создании и клике по чекбоксу выполнения.

3. **Кнопка добавления колонки «+ Добавить колонку»**:
   - На Канбан-доске справа от крайней колонки добавлена призрачная кнопка равной ширины (`w-72 shrink-0`) с пунктирным бордером `border-dashed border-subtle/80`.
   - Инлайн-форма ввода названия новой колонки с автофокусом, созданием по `Enter` и отменой по `Escape`.

4. **Архитектурный фундамент v2 и Cycle Guard**:
   - Реализована защита от бесконечных рекурсивных циклов (`Cycle Guard`) в EventBus через счетчик глубины цепочки в `context.Context` (не более 3 автоматизаций на одно действие пользователя).
   - Поддержка `column_id` во всех слоях DDD: domain, application ports/usecases, infrastructure db/sqlc, http handlers.
