## 🧠 1. Зафиксированные микро-решения спринта (Preserved Micro-Decisions)

* **Бизнес-цель**: Устранить четыре мелких UX-раздражителя за один быстрый спринт (S-размер задач, без изменения схемы БД и контрактов OpenAPI).
* **Ключевые продуктовые правила и UI решения**:
  1. **TASK-B10 — Ребрендинг «SLA»**:
     - Замена непонятной технической аббревиатуры «SLA» на человекопонятные термины в интерфейсе конструктора автоматизаций.
     - `column_sla_timer` → «Задержка в колонке» (задача в колонке дольше N часов).
     - Параметр «Порог нахождения:» → «Задача в колонке дольше чем:».
     - API-код `column_sla_timer` и бэкенд сохранены без изменений.
  2. **TASK-B07 — Авто-названия автоматизаций + бейдж #A-NN**:
     - Формат авто-названия правил отвязан от имени колонки: `[Триггер] → [Действие]`.
     - Карточки правил получили компактный моноширинный бейдж `#A-01`, `#A-02` по индексу в списке воркспейса.
     - Существующие правила со старыми названиями сохранены без изменений.
  3. **TASK-B11 — Клавиатурная навигация в выпадающем списке тегов**:
     - Полноценная навигация с клавиатуры без отрыва рук: `ArrowDown`/`ArrowUp` (циклический wrap-around), `Enter` для быстрого выбора выделенного тега, `Escape` для закрытия списка.
     - При вводе в текстовое поле индекс сбрасывается (`-1`). Автоскролл `scrollIntoView({ block: 'nearest' })` на активный элемент.
  4. **TASK-B04 — Счётчик только активных задач на карточке доски**:
     - SQL-запрос `CountActiveTasksByBoard` в `backend/queries/projects.sql` подсчитывает реальный объём работы: `COUNT(*) FILTER (WHERE is_completed = false AND parent_id IS NULL)`.
     - На карточке доски в боковой панели выводится `X колонок · Y в работе` (если Y = 0 → `нет задач`).
